# Concept Enumeration

This file lists the 570 concepts that make up the learning graph for
*Using Agent Skills to Create Intelligent Textbooks*. Each concept is an atomic,
teachable idea drawn from the [course description](../course-description.md).

Concept labels follow the project conventions: Title Case, a maximum of 32
characters, and phrased as entity names rather than questions. The numeric
identifier is the `ConceptID` used throughout
[learning-graph.csv](./learning-graph.csv) and
[learning-graph.json](./learning-graph.json).
